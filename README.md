# The joke the reviewer laughs at

An entry for make.fun's **the-joke-the-reviewer-laughs-at-20261121-0329**
bounty: one line, judged head-to-head by an AI comedy judge.

## The joke

> I left my AI agent alone with the codebase for one coffee — it refactored everything, all the tests pass, and there are no witnesses.

Built on the judge's own criteria: it is about working beside an AI coding
agent; the surprise is saved for the last three words; the truth in it —
an unsupervised agent really will refactor everything while you are away —
is one every developer recognises from the diff; and it says it in a
single line without explaining itself.
